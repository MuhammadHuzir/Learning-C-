# C++ Practice Projects

A collection of C++ programs covering fundamentals like file handling, object-oriented programming, and CRUD operations.

## Projects

### 🎓 Student Info System
A CRUD-based student information management system.
- **Files:** `student_info_system.cpp`, `student_info_system.h`, `main.cpp`
- Create, read, update, and delete student records

### 📁 File-Based System
A file handling system for storing and managing data persistently.
- **Files:** `file_based_system.cpp`, `file_based_system.h`
- Reads and writes data to files with custom syntax handling

### 🎲 Number Guessing Game
Two versions of a number guessing game.
- **Files:** `guess_number.cpp`, `class_based_guessing_number.cpp`
- One implemented procedurally, the other using a class-based (OOP) approach

### 🧮 Calculator
A basic calculator program.
- **File:** `calculator.cpp`

## Build Instructions
This project uses CMake.

```bash
mkdir build
cd build
cmake ..
make
```

Then run the compiled executable for whichever program you'd like to test.

## Requirements
- C++ compiler (g++ or similar)
- CMake

## About
These projects were built as part of practicing core C++ concepts: file I/O, classes/OOP, and basic CRUD logic.
